# DW드론 조종기 앱 설치 (안드로이드 폰)

플러터(Flutter)나 개발 도구는 필요 없어요. 완성된 설치 파일(`DW드론.apk`)만 받으면 돼요.

1. 폰 크롬에서 이 저장소의 `d18_드론비행/앱/DW드론.apk` 를 열고 **다운로드** 버튼을 누른다.
2. 알림창의 `DW드론.apk` 를 눌러 연다. "출처를 알 수 없는 앱" 허용 창이 나오면 **이 출처 허용** 을 켠다.
3. **설치** 를 누르고 **열기** 를 누른다. 앱 이름은 `DW드론` 이다.
4. 위치 권한 창이 나오면 **앱 사용 중에만 허용**(안드로이드 12 이상은 **근처 기기** 도 허용)을 누른다.
5. 찾기 화면에서 내 보드 이름을 누르면 연결된다. 이름은 영문·숫자(8글자 이하)이고, 한글 이름도 보인다.
6. 보드에는 `main_비행_앱/main.py` 를 올려 둔다. 앱 위쪽에 배터리 전압과 블루투스 신호가 보인다.

아이폰은 이 앱 대신 교재의 nRF Connect 방식을 쓴다.
