# D18 명령문 — 복사해서 붙여 넣기

> 코드 상자의 글자를 **드래그해서 복사**하거나 상자 오른쪽 위의 **복사 단추**를 눌러 붙여 넣는다.
> 한 줄씩 붙여 넣고 `Enter` 를 누른다. 붙여 넣기: 윈도우는 마우스 오른쪽 버튼 또는 `Ctrl+V`, 맥은 `Cmd+V`.

## 1. 토니 안의 esptool 을 4.8.1 로 맞추기 (컴퓨터마다 한 번)

토니를 닫고 한다. 첫 줄 → 결과 확인 → 둘째 줄 순서이다.

### 윈도우 — 명령 프롬프트(cmd)
검색창에 `cmd` 를 쳐서 [명령 프롬프트]를 연다.

먼저 (토니 파이썬이 있는지 확인, 파일 이름이 한 줄 보이면 그대로 진행):
```
dir "%LOCALAPPDATA%\Programs\Thonny\python.exe"
```

첫 줄 (설치, 끝에 `Successfully installed esptool-4.8.1` 이 보이면 성공):
```
"%LOCALAPPDATA%\Programs\Thonny\python.exe" -m pip install esptool==4.8.1
```

둘째 줄 (버전 확인, 결과에 `4.8.1` 이 보이면 끝):
```
"%LOCALAPPDATA%\Programs\Thonny\python.exe" -m esptool version
```

> 토니를 "모든 사용자용"으로 깔았다면 파일이 `C:\Program Files\Thonny\python.exe` 에 있을 수 있다. 이때는 [명령 프롬프트]를 **관리자 권한으로 실행**하고 위 두 줄의 경로를 그 경로로 바꿔 쓴다 (강사 PC 에서는 확인하지 못했다).

### 맥 — 터미널
`Cmd+Space` 로 검색을 열고 `터미널` 을 쳐서 연다. 토니는 닫는다.

첫 줄 (설치 — 토니 앱 폴더가 관리자 소유라 `sudo` 와 컴퓨터 **암호**가 필요하다. 입력하는 글자는 화면에 안 보이는 것이 정상이다):
```
sudo /Applications/Thonny.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 -m pip install esptool==4.8.1
```

둘째 줄 (토니와 같은 방식으로 버전 확인, 결과에 `4.8.1` 이 보이면 끝):
```
/Applications/Thonny.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 -s -m esptool version
```

> 반드시 `sudo` 를 붙인다. `sudo` 없이 설치하면 사용자 폴더에 깔려서 토니가 읽지 못한다.
> 앞서 `sudo` 없이 설치한 적이 있다면 먼저 그 복사본을 지운 뒤 위 첫 줄을 다시 한다:
> ```
> /Applications/Thonny.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 -m pip uninstall -y esptool
> ```
> 끝나면 토니를 다시 열고, 파일 고르는 창(설치 창)에서 `pyDrone_0118.bin` 을 고른다.
> 강사 맥에서 위 순서로 4.8.1 로 교체한 뒤 토니 설치 창에서 `pyDrone_0118.bin` 을 골라 바꾸기까지 성공했다 (2026-10-22).

## 2. 토니 쉘에 쓰는 한 줄 — 펌웨어 확인

토니 아래쪽 **쉘** 창에 붙여 넣고 `Enter` 를 누른다.

```
import drone
```

- 글자 없이 `>>>` 로 돌아오면 → pyDrone **v1.18** 이다 (drone 모듈이 들어 있다).
- `ImportError: no module named 'drone'` 이 나오면 → 일반 **v1.29** 이다. 슬라이드의 굽기 순서로 v1.18 로 바꾼다.

## 3. 굽는 파일
- 학생 저장소 `d18_드론비행/펌웨어/pyDrone_0118.bin` (이름 끝의 `0118` = 펌웨어 v1.18)
- 토니: 오른쪽 아래 인터프리터 → `Install or update MicroPython (esptool)` → 파일 열기 창에서 위 파일 선택 → `[Install]`
